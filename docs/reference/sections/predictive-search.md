# Predictive Search

> **File:** `sections/predictive-search.liquid` · **Area:** Search · **Size:** 446 lines

## What it does

Returns the live search suggestions (products, collections, pages, articles, and the matched query) while a customer is typing in the search box. It has no editor settings.

## Where it appears

Not placed on a page. Used by the search popdown..

**Can be added from the theme editor:** no (internal or fixed section).
